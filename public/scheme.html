Поток запроса (пошагово)

[ViewController] → вызывает метод сервиса [Service] → формирует DTO, вызывает APIClient.request(path, method, body, authorized) [APIClient] → URL, Headers (Accept, Content-Type, Authorization), body → JSON (snake_case), URLSession.data(for:) [Сеть] → HTTPS на https://anton.panfilius.ru/api/... [Laravel API] → обрабатывает, возвращает JSON [APIClient] → statusCode, decode DataWrapper | APIResponse | T, при 401/422 — APIError [Service] → возвращает модель, при логине — сохраняет token в Keychain, при корзине — NotificationCenter [ViewController] → обновляет UI

Форматы ответов API

  • Успех (2xx): {"data": T} → разворачивается в T; {"success": true, "data": T} → T; прямой T или [T]
  • 401: тело с полем message → APIError.unauthorized
  • 422: тело с полем errors: { "field": ["msg"] } → APIError.validation
  • Остальные: → APIError.badStatus(code, message)
